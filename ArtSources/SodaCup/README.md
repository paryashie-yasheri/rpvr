# Soda cup source

Downloaded archive: `soda-cup.zip`, original file `source/cc0 soda cup.blend`.
The original Blender file is retained here outside Unity Assets to avoid depending on Unity's Blender importer.
Exported mesh: `beach-cafe/Assets/BeachRestaurant/Models/SodaCup/SodaCup.fbx`.
Export settings: mesh objects only, apply unit scale, forward -Z, up Y, no animation. Unity materials recreated from the source blue/white/red material colors.
